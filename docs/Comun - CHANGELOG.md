# CHANGELOG

Todas las novedades relevantes del proyecto se documentan en este archivo.

El formato sigue Keep a Changelog y el versionado sigue SemVer
(`MAJOR.MINOR.PATCH`):

- **MAJOR**: cambios que rompen la compatibilidad o reorganization fuerte del
  repositorio.
- **MINOR**: funcionalidad nueva compatible con lo anterior.
- **PATCH**: correcciones de errores que no alteran la funcionalidad.

Las versiones de los documentos siguen **DocVer** (`v1.0.0`), según lo pedido en
las consignas de las actividades 5 a 8.
