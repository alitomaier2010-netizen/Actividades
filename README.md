Este repositorio central funciona como **punto de entrada y rama explicativa**.
Cada actividad se desarrolla y entrega en su **rama propia**; en `main` no se
acumula código, para mantener limpio el historial y facilitar la revisión.

| Rama | Actividad | Resumen |
|:----:|-----------|---------|
| `actividad-1` | 1 — Revisión integral (Python & C++) | Calculadora de edad exacta, validación de calendario y años bisiestos. |
| `actividad-2` | 2 — El Taller del Programador | Primer "Hola Mundo" en C++. |
| `actividad-3` | 3 — Cálculo de área (modular, top-down) | Prototipo + implementación de función, diana en ASCII. |
| `actividad-4` | 4 — Cadenas y punteros | Control de acceso por edad manipulando la RAM con punteros. |
| `actividad-5` | 5 — Struct y punteros | Modelado de datos con `struct` y operador flecha. |
| `actividad-6` | 6 — Taller de repaso | Recursividad, búsqueda secuencial, intercambio con punteros. |
| `actividad-7` | 7 — Piedra, papel o tijera + persistencia | `struct` + `fstream` (ofstream/ifstream, `ios::app`). |
| `actividad-8` | 8 — Juego de naves (POO) | `class Nave`, `Asteroide`, `Bala`, encapsulamiento. |
