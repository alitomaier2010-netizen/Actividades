# Manual del Usuario — v1.0.0

**Proyecto:** Actividad 6 — Taller de Repaso General
**Materia:** LPR — E.E.S.T. N° 1 "Eduardo Ader"

## 1. Requisitos

- Compilador C++ (MinGW/MSYS2) o navegador para usar OnlineGDB.

## 2. Ejecución

1. Compilar con `g++ "src/main.cpp" -o "src/repasogeneral.exe"`.
2. Ejecutar `.\src\repasogeneral.exe`.
3. Ver en pantalla los tres retos y las direcciones hexadecimales de memoria.

## 3. Salida esperada

- RETO 1: `Suma acumulada de 1 hasta 5: 15`.
- RETO 2: valor `18` hallado en índice `[6]` con su dirección RAM.
- RETO 3: valores intercambiados, `X: 500 | Y: 100`.

## 4. Troubleshooting

- Si no hay permisos para compilar en el laboratorio, usar OnlineGDB y tomar capturas.
- Si el compilador no se encuentra, revisar la variable de entorno PATH.
